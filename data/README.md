# WeatherArchive-Bench Data

This directory contains the core datasets for the two benchmark tasks in WeatherArchive-Bench: **WeatherArchive-Retrieval** and **WeatherArchive-Assessment**. All files are in CSV format.

## Dataset Overview

| File | Rows | Used By | Description |
|------|------|---------|-------------|
| `QACandidate_Pool.csv` | 335 | Assessment (Classification + RAG) | 100 candidate passages per query for both evaluation tasks |
| `QACorrect_Passages.csv` | 335 | Retrieval + Assessment | Gold query-passage pairs (ground truth for retrieval) |
| `ground_truth_climate.csv` | 335 | Assessment (Classification) | Expert-annotated vulnerability/resilience labels per query |
| `output-top3.csv` | 335 | Assessment (RAG) | Top-3 retrieved passages from the default retrieval model |
| `output-top3_ANCE.csv` | 335 | Assessment (RAG) | Top-3 retrieved passages from ANCE |
| `output-top3_Gemini.csv` | 335 | Assessment (RAG) | Top-3 retrieved passages from Gemini Embedding |

## Task-to-Dataset Mapping

### WeatherArchive-Retrieval

The retrieval task evaluates how well models can locate the correct passage from a large corpus given a weather-related query. The relevant data lives in two places:

- **`QACorrect_Passages.csv`** (this directory) -- The 335 gold query-passage pairs used as ground truth for computing Recall, MRR, and nDCG.
- **`../WeatherArchive_Retrieval/qa_pair/`** -- The operational retrieval data:
  - `queries.csv` -- Query set (one query per row).
  - `correct_passages.csv` -- Same gold passages aligned 1-to-1 with `queries.csv`.
  - `concatenated_chunks.csv` -- The full document corpus (1M+ passages). This file is stored via Git LFS; see the file header for a Google Drive download link if LFS is unavailable.

Retrieval evaluation scripts read from `../WeatherArchive_Retrieval/qa_pair/` and write results to `../WeatherArchive_Retrieval/output/`.

### WeatherArchive-Assessment

The assessment task has two sub-tasks, both of which use the same 335 queries:

#### Sub-task 1: Societal Vulnerability and Resilience Indicator Classification

Given a query and its correct passage, an LLM classifies the event along six IPCC-aligned dimensions. This is a structured multi-label classification task.

- **Input:** `QACandidate_Pool.csv` -- Each row provides a query, the index of the correct passage (`correct_passage_index`), and 100 candidate passages (`passage_1` ... `passage_100`). The script uses the correct passage for classification.
- **Ground truth:** `ground_truth_climate.csv` -- Expert annotations for the six classification fields.
- **Evaluation:** `../WeatherArchive_Assessment/src/classification_metrics.py` computes per-field and overall accuracy, F1, precision, and recall.

#### Sub-task 2: Free-form Question Answering (RAG)

Given a query and retrieved passage(s), an LLM generates a free-form answer. This evaluates end-to-end RAG quality.

- **Input (with retrieval):** `output-top3.csv` / `output-top3_ANCE.csv` / `output-top3_Gemini.csv` -- Each row contains a query and the full text of its top-3 retrieved passages. These are fed as context to the LLM.
- **Input (gold passages):** `QACorrect_Passages.csv` -- Used by `rag_eval_gold.py` to measure ceiling performance with perfect retrieval.
- **Ground truth:** Generated by GPT-4.1 as the oracle model (stored in `../WeatherArchive_Assessment/output/ground_truth_QA.csv` after running).
- **Evaluation:** `../WeatherArchive_Assessment/src/QA_metrics.py` computes BLEU, ROUGE-1, ROUGE-L, and BERTScore.

## File Schemas

### QACandidate_Pool.csv

| Column | Type | Description |
|--------|------|-------------|
| `id` | int | Query identifier (1-335) |
| `query` | str | Weather-related question about historical events |
| `correct_passage_index` | int | 1-based index indicating which `passage_N` column is the correct answer |
| `passage_1` ... `passage_100` | str | 100 candidate passages from the archival corpus |

### QACorrect_Passages.csv

| Column | Type | Description |
|--------|------|-------------|
| `id` | int | Query identifier (1-335) |
| `query` | str | Weather-related question |
| `correct_passage` | str | The single gold-standard passage that answers the query |

### ground_truth_climate.csv

| Column | Type | Description |
|--------|------|-------------|
| `query` | str | Weather-related question |
| `correct_passage_context` | str | The passage used for classification |
| `model_id` | int | ID of the model that produced the ground truth |
| `model_name` | str | Name of the ground truth model (GPT-4.1) |
| `region` | str | Geographic region extracted from the passage |
| `exposure` | str | Hazard type: `Sudden-Onset`, `Slow-Onset`, or `Compound` |
| `sensitivity` | str | Impact severity: `Critical`, `Moderate`, or `Low` |
| `adaptability` | str | Recovery capacity: `Robust`, `Constrained`, or `Fragile` |
| `temporal` | str | Temporal scale: `short-term absorptive capacity`, `medium-term adaptive capacity`, or `long-term transformative capacity` |
| `functional` | str | Most affected system: `health`, `energy`, `food`, `water`, `transportation`, or `information` |
| `spatial` | str | Geographic scale: `local`, `regional`, or `national` |

### output-top3.csv / output-top3_ANCE.csv / output-top3_Gemini.csv

| Column | Type | Description |
|--------|------|-------------|
| `query` | str | Weather-related question |
| `top_1_text` | str | Full text of the rank-1 retrieved passage |
| `top_2_text` | str | Full text of the rank-2 retrieved passage |
| `top_3_text` | str | Full text of the rank-3 retrieved passage |

## Example Usage

### Loading the retrieval ground truth

```python
import pandas as pd

# Load gold query-passage pairs
correct = pd.read_csv("data/QACorrect_Passages.csv")
print(f"Number of queries: {len(correct)}")
print(f"Columns: {list(correct.columns)}")

# Show a sample query and its correct passage
row = correct.iloc[0]
print(f"\nQuery: {row['query'][:120]}...")
print(f"Passage: {row['correct_passage'][:120]}...")
```

### Loading the classification ground truth

```python
import pandas as pd

# Load expert-annotated vulnerability/resilience labels
gt = pd.read_csv("data/ground_truth_climate.csv")
print(f"Number of samples: {len(gt)}")

# Show label distributions
for col in ["exposure", "sensitivity", "adaptability", "functional", "spatial"]:
    print(f"\n{col}:")
    print(gt[col].value_counts())
```

### Loading the candidate pool for assessment

```python
import pandas as pd

# Load the candidate pool (100 passages per query)
pool = pd.read_csv("data/QACandidate_Pool.csv")
print(f"Number of queries: {len(pool)}")
print(f"Passages per query: 100")

# Get the correct passage for the first query
row = pool.iloc[0]
correct_idx = int(row["correct_passage_index"])
correct_passage = row[f"passage_{correct_idx}"]
print(f"\nQuery: {row['query'][:120]}...")
print(f"Correct passage index: {correct_idx}")
print(f"Correct passage: {correct_passage[:120]}...")
```

### Loading retrieved passages for RAG evaluation

```python
import pandas as pd

# Load top-3 retrieved passages from different models
for model in ["output-top3", "output-top3_ANCE", "output-top3_Gemini"]:
    df = pd.read_csv(f"data/{model}.csv")
    print(f"{model}: {len(df)} queries with top-3 passages each")

# Use retrieved passages as context for RAG
df = pd.read_csv("data/output-top3_Gemini.csv")
row = df.iloc[0]
context = "\n\n".join([row["top_1_text"], row["top_2_text"], row["top_3_text"]])
print(f"\nQuery: {row['query'][:120]}...")
print(f"Combined context length: {len(context)} characters")
```
